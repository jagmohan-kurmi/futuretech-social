## Last slide + CTA standard (every carousel) - "professional CTA system"
1. **Recap card** - 3 takeaways with icons (what to fix first).
2. **Primary CTA** - one only: big green WhatsApp button "WhatsApp par baat karein", number 79742 17411 in large type. The button is the largest element on the slide.
3. **Pre-filled link / QR** - wa.me link with lead code (e.g. `?text=Namaste%20(IG-C05)`); flat QR code on the slide for viewers on desktop.
4. **Trust line** - "Sagar (MP) se, poore India ke liye" + website.
5. **Secondary** - Save karein / Dost ko bhejein (small, below).
6. **Segment line** (one sentence), e.g. Gym: "Apne gym ka 30-din plan banwana hai? WhatsApp karein."
7. Rules: one CTA, no fake urgency ("limited seats"), no "free" offer unless founder confirms in chat, no unverified claim, contrast AA, number >= 80px on 1080 canvas, safe margins 72px, footer unchanged.
Reel end card (last 2 s): logo + WhatsApp number + website. Single post: footer bar already carries WhatsApp + website; caption holds the pre-filled link.
Per platform: IG caption ends "WhatsApp karein + Save karein"; FB caption has wa.me link (FB-code); GBP button Learn more -> website (UTM).
