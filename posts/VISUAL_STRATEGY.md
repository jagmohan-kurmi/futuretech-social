# FutureTech Social — Visual Strategy (v1, 10 Nov 2026)

Goal: every post looks like a designed brand system, not a filled template. Professional, flat, trustworthy, instantly readable on a phone.
Works with: Brand Kit, Publishing Rulebook, Content Creation Rulebook, `posts/CONTENT_PLAN_Nov-Dec_2026.md`.

## 1. Why earlier posts felt "template-like" (diagnosis)
- Too much text per post (card + card + 3-point list). Eye has no single entry point.
- Small illustrations; no hero visual. Headline and visual compete.
- Same list-box layout reused for every topic.
- Carousel slides were text + a small mockup; no strong cover.

## 2. Design principles (new)
1. **One post = one idea = one hero visual.** Hero takes 40-50% of the canvas.
2. **3-second rule.** A scrolling viewer must understand the topic from headline + hero alone.
3. **Big, short headline.** Hindi (Devanagari, Mukta 800) max 8 words / 3 lines, 90-110px on 1080 wide. Key word in Royal Blue or Gold marker.
4. **Max ~25 words in total** on a single image (carousel slide: headline + max 2 short lines).
5. **Real-world visuals as flat illustration**: browser window, phone, Google search bar, Maps pin, WhatsApp chat, listing card. Dotted connector lines to show "how things connect".
6. **Consistent system, varied compositions**: same logo/footer/chips/type; layout changes per post type.
7. **Business is always named** on carousels/ads posts (cover badge): "Coaching & College ke liye", "Clinic & Doctor ke liye", "Dukaandaar ke liye", "Service business ke liye". Generic posts say "Har business ke liye".
8. Never: neon/glow, floating particles, 3D chrome, emoji icons, fake stars/ratings, AI faces, fake names/numbers/results.

## 3. Visual system
| Element | Rule |
|---|---|
| Background | Cloud White #F4F7FB flat; hero sits on a soft #E6EEF8 panel with 40px radius |
| Text colors | Navy #041030 headline; Royal Blue #0060A8 key word; Diya Gold #FFC94D marker only; WhatsApp Green #22C55E only for WhatsApp |
| Fonts | Mukta 800 headline, Mukta 600 sub, Poppins for Roman/footers. No third font |
| Illustration | Flat shapes, navy outline 4-5px on main object, rounded corners, 3-4 brand-tint fills (#FFE7A8, #BFE3F7, #CFE7D8). Real-UI colors allowed for recognisable objects (Maps red pin, WhatsApp green) |
| Icons | Flat line SVG, 2px stroke, Royal Blue |
| Header | Logo top-left 60-70px; chip top-right (post type or audience) |
| Footer | Navy bar; WhatsApp dot + 79742 17411 + website. GBP: no phone number |
| Safe zones | Feed: 72px side margin. Story/Reel: top 250px, bottom 340px clear |

## 5. Carousel formula (all segments)
1. **Cover**: audience badge (blue pill), hook as a question, hero mockup, "Swipe" in footer.
2. **Slides 2-6**: one cause/step each. Layout: "कारण/Step n" chip (top-right), headline (2 lines), 1 supporting line, one visual. Visual changes every slide (never 3 list cards in a row).
3. **Slide 7**: CTA card (navy) - WhatsApp + "Save / Share" buttons. No fake offers.
4. Same slides re-sized for IG 1080x1350, FB 1080x1080; GBP gets a single summary image.

## 8. Quality gate before any preview is sent
- 3-second test: topic clear from headline + hero?
- Text <=25 words; smallest text >=26px on 1080 canvas (>=22px for labels only).
- Fonts loaded (Mukta/Poppins); no overflow; footer clear; safe zones respected.
- Brand colors only; no banned elements; no unverified claims/prices; alt text written; lead code present.
- Check IG, FB and GBP versions visually, then send previews. Nothing is scheduled without founder's explicit OK.
